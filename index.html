🧩 PC's Sudoku 🧩

📖 How to Play

🔢 Sudoku:Fill in numbers 1–9 so that each row, each column, and each 3×3 box contains no repeats.
🎯 Killer Sudoku:Sudoku rules + the numbers inside each dashed cage must add up to the given clue.
🎮 2048:Slide the tiles in a direction. Matching numbers merge. Reach 2048.
🔴🔵 Oh h1:Click to switch between red and blue. No three in a row of the same color. Each row and column must have the same number of red and blue.
🖼️ Nonogram:Fill in the cells according to the numbers in the clues to complete the picture.
🧮 Nerdle:Guess the equation.Green: correct. Purple: correct symbol, wrong position. Black: wrong.
💣 Minesweeper:Left-click to reveal a tile. Right-click or long-press to place a flag for a mine. Numbers show how many mines are nearby.
🎯 Mastermind:Guess the secret color code. Black peg = right color, right position. White peg = right color, wrong position.
🧮 KenKen:Fill grid with 1-N. Each row/col must be unique. Cages must met target using operation.
🔧 Pipe:Rotate pipes to connect all to the power source. Click to rotate 90°. Light up all Bulbs to win.
